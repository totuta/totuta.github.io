근데 왜 $\sqrt{d_k}$ 로 나눠서 Scaling 은 왜 하지?

$$
  \mathrm{Attention}(Q, K, V) =
\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

Not completely statistically precise, but statistical enough.

$d_k$ 의 차원수를 갖는 랜덤 벡터 간의 내적의 분산이 $d_k$ 이고, 표준 편차는 $\sqrt{d_k}$.

그래서 이것의 sqrt 로 나누어서(scaling) normalization 을 하겠다는 것.

정규화를 안하면,
- Dot product 값이 극단적으로 커질 수가 있고
- 컴퓨터로 softmax 를 계산하게 되는데, 수치적 불안정성을 유발할 수 있음

여기서 torch code 한 번 눈에 넣어놓고,
```ts
export function scale(dot: number, dimension: number) {
  return dot / Math.sqrt(dimension);
}
```
