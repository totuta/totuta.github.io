那为什么要用 `sqrt(d_k)` 来做 scaling 呢？

$$
  \mathrm{Attention}(Q, K, V) =
\mathrm{softmax}\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

这不是完全严格的统计推导，但作为直觉已经足够。

对于维度为 `d_k` 的随机向量，它们的点积方差大致会随 `d_k` 增大，而标准差大约是 `sqrt(d_k)` 的量级。

所以我们除以 `sqrt(d_k)` 来做 scaling，目的就是把数值尺度规范下来。

如果不做这个归一化:

- dot product 可能会变得非常大
- softmax 的数值计算可能出现不稳定

这里先看一下 torch 风格的代码：

```ts
export function scale(dot: number, dimension: number) {
  return dot / Math.sqrt(dimension);
}
```
